# Lenovo Legion Go family

This backend independently implements the device protocols described by these pinned sources. It
does not distribute SapientiaUsb, HC code or HC illustrations.

Primary Windows reference:
[Handheld Companion a250b19](https://github.com/Valkirie/HandheldCompanion/tree/a250b19a4b7e29dac3b383f2d1ac517d1af43e4e).
Secondary cross-check: [HHD a87fb30](https://github.com/hhd-dev/hhd/tree/a87fb308).

The Go S DirectInput byte layout is not established by HC or HHD; this implementation asks Windows
to parse its real Generic Desktop descriptor instead of applying tablet byte offsets. HC's Go 2
left-gyro Z inversion is still marked TODO in the reference, so this backend retains the actual HC
decoder rather than guessing a firmware-specific correction. Controller mapping factory resets are
not issued implicitly: they overwrite persistent mappings and neither reference provides a readable
original mapping transaction. No vendor artwork is embedded; consumers use their generic fallback.

Compilation and source regression coverage are distinct from physical acceptance. These additional
Lenovo models have not been hardware-tested by this port.
