# HHD device and capability inventory

HHD 4.1.12, [a87fb308f9f14d4a78ef3cb0b8515827459f8466](https://github.com/hhd-dev/hhd/tree/a87fb308f9f14d4a78ef3cb0b8515827459f8466), snapshot date 2026-09-30. Local reference: `D:\Coding\WSGM\_ref\hhd`.

Static Linux-source evidence for Windows-first .NET LibHandheld. HC is primary, HHD secondary and OpenGamepadUI tertiary. Every Linux-only transport needs independent Windows implementation. No hardware testing or Windows support is claimed.

## Coverage

- 84 exact controller rows plus four ASUS substring ranges.
- Seven generic controller fallback ranges, two CPU power fallback ranges.
- One explicit CPU controller subvariant: GPD Win 4 8840U.
- 35 unified board and 21 unified product power rows; 10 legacy model rows, five ASUS rows, four MSI rows and five Intel presets.
- Three Aura secondary classes, excluded from handheld counts.
- Thirteen touchscreen orientation rows; two additional auxiliary models, Steam Deck LCD (`Jupiter`) and OLED (`Galileo`), without dedicated HHD controller profiles.
- 111 records and 111 examined source files. Full identities, profile data and feature evidence: [hhd.json](hhd.json).

Each row is a source profile/identity, not necessarily a distinct marketed device. Shared display names do not merge aliases, AOKZOE models or OXP special editions.

## Shared conditional mechanisms

Generic fan providers are `oxp_ec`, `gpdfan`, `ayaneo_ec`, `thinkpad`, and legacy `oxpec`; ThinkPad needs fan_control enabled. Temperature discovery checks amdgpu/k10temp/coretemp. Unified power providers are amd-dptc, lenovo-wmi-gamezone, asus-wmi, thinkpad-acpi-profile and samsung-galaxybook, with actual available choices required. These are provider ranges, not additional named models. Battery threshold/bypass is discovered from power_supply; legacy charge_type bypass is ONE-NETBOOK-gated. Generic LEDs match multicolor:chassis or :rgb:joystick_rings. General no-device fallback selects PowerProfiles via DBus, rather than implementing numerical TDP.
