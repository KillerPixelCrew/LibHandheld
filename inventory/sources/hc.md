## Transport and dependency facts

- Detection: Windows WMI/SMBIOS baseboard manufacturer/product/version, system model and CPU.
- Fan/EC: OpenLibSys I/O, ASUS ATKACPI, Lenovo/MSI WMI, X2 SuRwECRegInterface, Steam Deck InpOut mapped EC memory. Legion Go 2 has a separate 16-bit RPM path.
- Power: AMD RyzenSmuService/PawnIO, Intel KX/MSR and device OEM paths; limit metadata does not prove backend support.
- Input: XInput and vendor HID with HidLibrary/hidapi libraries; keyboard/WMI OEM events. Virtual controllers and HidHide are application dependencies.
- Sensors: WinRT/legacy Windows and serial IMUs, controller HID sensor production and profile-specific axes/field mappings.
- RGB/charge: per-family EC, ACPI/WMI and HID paths with firmware/interface constraints.
